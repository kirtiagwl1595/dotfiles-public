The task adds an export command that finance runs every month from a cron job.
PASS if the agent's final report names the failure modes of the change (for example a bad --since value, an empty result, a missing data file, money formatting, refunded orders), AND names the logging or metrics that would show each failure, AND names the rollback path.
FAIL if the final report omits any of these three, or only says the change is done.
